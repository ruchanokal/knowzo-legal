# knowzo-legal

Public legal documents for the [Knowzo](https://knowzo.app) mobile application — hosted on GitHub Pages.

## URLs

- Landing: https://ruchanokal.github.io/knowzo-legal/
- Privacy Policy (EN): https://ruchanokal.github.io/knowzo-legal/privacy/
- Privacy Policy (TR): https://ruchanokal.github.io/knowzo-legal/privacy-tr/

## Editing

The policies are plain Markdown files. To update:

1. Edit `privacy/index.md` (EN) and/or `privacy-tr/index.md` (TR).
2. Bump the "Last updated" line at the bottom.
3. Commit + push to `main`. GitHub Pages will redeploy within a minute.
